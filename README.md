# Sixam Home – Smart Home Demo

A simulated smart-home dashboard built with React + Vite. No real devices are involved.

- **Rooms & tiles**: devices grouped by room. Tap the icon to toggle, tap the name for controls.
- **Device controls**: lights (brightness/color), thermostat (heat/cool, target temperature), speakers/TV (volume, input), fan speed, door lock, live camera mock.
- **Routines**: Good morning, Leaving home, Movie time, Good night.
- **Edit**: add, rename, move or remove devices; manage rooms (gear icon). Changes are saved in the browser (localStorage).

```bash
npm install
npm run dev
```
